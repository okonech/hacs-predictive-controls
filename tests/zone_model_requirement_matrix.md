# Zone Model Requirement Matrix

This Phase 1 inventory records the reviewed pre-target test surface and its
completed disposition. `Preserve` keeps the public fact, outcome, or
model-independent contract. `Replace` names the executable target replacement.
`Retire` records implementation-specific coverage removed after its named target
coverage passed and the exact engine was removed in Phase 8.

The baseline contained 53 `tests/test_*.py` modules. The Phase 1 schema gate
`test_zone_model_fixture_schema.py` is new and is therefore not counted as a
baseline module.
